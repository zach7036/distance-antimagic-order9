# Paper 2: Finite-field constructions

This folder records the second proof-based manuscript in the distance-antimagic research suite. It develops algebraic constructions for group-distance-antimagic Cayley graphs over finite fields and includes general theorems, dimensional families, limitations of the method, and explicit checked examples.

See the repository root README and RELEASE_NOTES.md for the current theorem list, scope, and status. This is a research draft and has not yet been peer reviewed.
