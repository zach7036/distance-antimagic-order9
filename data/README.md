# Graph catalogues

No large catalogue is embedded or encoded in this repository.

- Orders 1–7 are regenerated exactly from NetworkX's Graph Atlas by `code/generate_lower_catalogues.py` and hash-checked.
- Orders 8–9 are downloaded directly from Brendan McKay's ANU Combinatorial Data collection by `code/download_catalogues.py` and hash-checked.

Canonical external-catalogue hashes:

```text
546a249902101c97d3aa590f93e53366854bd0a6f405aa59bdb32d25c57f845a  graph8.g6
839f67ecc73b1f539128694badebe27adf4f0fb1ee6d0663b7ad9868100d5123  graph9.g6
```

Authoritative source page: <https://users.cecs.anu.edu.au/~bdm/data/graphs.html>.
