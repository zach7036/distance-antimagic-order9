# Paper 1: Universal Distance-Antimagic Labelings

This folder documents the proof-based universal-labeling branch of the project. The main result classifies graphs for which every cyclic group labeling is distance antimagic and proves that this is equivalent to universality over every abelian group of the same order. The only surviving graphs are complete graphs and perfect matchings.

Additional results cover universal subset-sum systems, exact signed-sum supports for ordinary labels, structural graph families, elementary abelian two-group labelings, and complementary-neighborhood obstructions.

See the repository root README and release notes for the theorem list and scope. The work is a research draft and has not yet been peer reviewed.
